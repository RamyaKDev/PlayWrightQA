# PlayWrightQA

JavaScript practice exercises for QA automation learning, covering basic language features, algorithms, callbacks, promises, async/await, and user input.

## Prerequisites

- Node.js 18 or later
- npm

## Installation

1. Clone the repository.
2. Open a terminal in the project directory.
3. Install the dependency:

   ```bash
   npm install
   ```

## Usage

Run an exercise with Node.js. For example:

```bash
node calculator.js
node promise.js
node Javascript/exercise.js
```

Some exercises read values from the terminal. Follow the prompts when they appear.

## Contents

- Core JavaScript examples in the project root
- Additional beginner exercises in `Javascript/`
- Algorithm practice for numbers, strings, searching, and palindromes
- Asynchronous JavaScript examples using callbacks, promises, and async/await

## Notes

This repository is an evolving learning project. File names and examples may change as new QA and JavaScript exercises are added.
